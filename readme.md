# YouTube Backend API

A backend REST API for a YouTube-like video platform built with Node.js, Express.js, MongoDB, Mongoose, and Cloudinary.

This project was built to practice backend development concepts such as REST APIs, authentication, database relationships, file uploads, and media management.

---

## Features

- User registration and login
- JWT-based authentication
- Access and refresh token management
- Secure logout
- Password change
- User profile management
- Avatar and cover image upload
- Video upload and management
- Publish and unpublish videos
- Video and thumbnail storage using Cloudinary
- Delete videos and thumbnails from Cloudinary
- Create, update, and delete comments
- Create and manage playlists
- Subscribe and unsubscribe from channels
- Create, update, and delete tweets
- Like functionality
- Video search and pagination
- Protected API routes

---

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JSON Web Token (JWT)
- Cloudinary
- Multer
- bcrypt
- Postman
